The GitHub mirror of CDSlow-5.2
MAIN FEATURES

    Program interface is organized as an icon in the taskbar, allowing you to quickly change the speed.
    Program can start automatically at logon, and set the required speed for the drives.
    It can restore speed after disk is changed, wakeup from hibernation, or by timer.
    It has the functions for opening/closing/locking the drive tray.
    Contains built-in ability to manage autorun functions.
    Hot keys are supported for open/close tray and change speed.
    Program can set a password for opening the drive tray.
    Can act as reminder of forgotten CD's at shutdown.
    Can save a copy of the settings in the file.
    Works with multiple drives.
    Can control optical drives from command line.
    Program has small size and can run without installation.
