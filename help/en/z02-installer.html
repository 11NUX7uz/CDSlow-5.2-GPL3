Installer options

To install CDSlow you may use the installer, or just extract archived files to the destination directory.

The installer has optional arguments:

/A- Register the program to start automatically after the silent install
/D=path- Select the installation directory
/H- Show the installer help
/NCRC- Don't check the files integrity
/R- Run the program after the silent install is finished
/S- Silent install
/?- Show the installer help
