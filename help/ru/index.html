CDSlow GPL 3+

CDSlow это программа для управления скоростью CD/DVD/Blu-ray приводов. Точнее, для ограничения максимальной скорости привода с целью уменьшить его шум, когда не требуется читать данные очень быстро (например, при прослушивании MP3). Заодно улучшает читаемость и предотвращает разрыв некачественных CD дисков в скоростных приводах. Имеет много дополнительных возможностей - управление лотком привода (EJECT/CLOSE), напоминание о забытых дисках, установка горячих клавиш, управление функцией автозапуска дисков.

ОСНОВНЫЕ ВОЗМОЖНОСТИ ПРОГРАММЫ

  • Интерфейс программы организован в виде иконки в панели задач, позволяя оперативно менять скорость.
  • Программа может автоматически запускаться при старте Windows и устанавливать требуемую скорость для приводов.
  • Может восстанавливать скорость после смены диска в приводе, при выходе из спящего режима, по таймеру.
  • Имеется функция открытия/закрытия/блокировки лотка привода (EJECT/CLOSE/LOCK).
  • Встроенная возможность управления автозапуском.
  • Назначение горячих клавиш для открытия/закрытия лотка и установки скорости.
  • Установка пароля на открытие лотка привода.
  • Напоминание о забытых дисках при выключении компьютера.
  • Сохранение копии настроек в файл.
  • Одновременная работа с несколькими приводами.
  • Управление скоростью и лотками приводов из командной строки.
  • Программа имеет небольшой размер и может работать без инсталяции.
