Параметры установки

Для установки CDSlow можно использовать инсталятор, или просто распаковать архив в любой каталог.

При запуске инсталятора доступны дополнительные параметры:

/A- Включить автозагрузку при пакетной установке
/D=path- Указать путь установки
/H- Справка по параметрам
/NCRC- Не проверять целостность файлов
/R- Запустить программу после пакетной установки
/S- Пакетная установка
/?- Справка по параметрам
